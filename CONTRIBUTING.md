# Contributing

Thanks for your interest in claude-remote-kit!

- **Bugs and ideas:** open an issue. Include your Windows version, WezTerm and Claude Code versions,
  and what you expected vs. what happened.
- **Pull requests:** keep them small and focused. Run the scripts you touched once on Windows before
  sending; for the monitor, start it on a spare port (`CRK_WEB_PORT`) and check it shows your sessions.
- **No personal data:** never commit `config.json`, `projects.txt` or anything under `state/`
  (keys and push subscriptions live there).

Translations of the README are welcome.
